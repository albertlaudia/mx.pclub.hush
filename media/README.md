# Media — Brand assets for prayer lock

This folder holds the brand and platform images for prayer lock. The `/media` directory is the single source of truth. Every platform (iOS, Android, web, marketing) draws from here.

## Files

### Brand mark
- `icons/app-icon-1024.png` — iOS App Store master (1024×1024, PNG)
- `icons/app-icon-512.png` — Android Play Store (512×512, PNG)
- `icons/favicon-{16,32,48,256}.png` — web favicons

### iOS app icon set
- `icons/ios/Icon-App-*.png` — every required size for the iOS asset catalog

### Android mipmap set
- `icons/android/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png`

### Marketing
- `social-preview-1280x640.png` — GitHub social preview
- See `docs/BRAND.md` for color tokens, typography, and the design system.

## The mark

**A white padlock with a small Christian cross carved into the body, on warm orange (#FF8B27).**

Why this mark:
- **The lock** = the wedge ("block your phone until you pray")
- **The cross** = the audience (Christian, multi-denominational)
- **The orange** = the brand (warm, energetic, not aggressive)
- **The white-on-orange** = readable on a home screen, on a notification, in a widget
